# Эмулятор оболочки UNIX (Вариант 19)

## Общее описание

Консольный эмулятор языка оболочки UNIX-подобной ОС на Python 3.9+
(сторонние библиотеки не нужны). Реализовано:

- этап 1 - REPL: приглашение из данных ОС, парсер кавычек, команды
  `ls`, `cd` (заглушки) и `exit`;
- этап 2 - конфигурация: параметры `--vfs`, `--script`, стартовый
  скрипт, отладочный вывод параметров;
- этап 3 - VFS: виртуальная файловая система в памяти, источник -
  каталог на диске, служебные команды `vfs-info` и `vfs-tree`.

## Описание функций и настроек

### Параметры командной строки

| Параметр        | Назначение                                        |
|-----------------|---------------------------------------------------|
| `--vfs DIR`     | Каталог на диске - источник VFS                   |
| `--script FILE` | Путь к стартовому скрипту с командами эмулятора   |
| `--help`        | Справка                                           |

Оба параметра необязательны. Пути проверяются на существование и
превращаются в абсолютные. Ошибка параметров - код возврата 2. При
запуске печатается отладочный вывод всех параметров:

    [debug] параметры запуска:
    [debug]   --vfs    = /abs/path/to/vfs
    [debug]   --script = <не задан>
    [debug] VFS загружена в память: каталогов 5, файлов 6, 93 B

### Виртуальная файловая система

Каталог из `--vfs` один раз читается с диска и целиком загружается в
память (структура и содержимое файлов). После загрузки диск не
используется: все операции выполняются только в памяти, файлы на
диске не распаковываются и не изменяются. Если каталог удалить после
запуска, VFS продолжит работать.

Особенности загрузки: символические ссылки и специальные файлы
(сокеты, каналы) пропускаются; скрытые файлы включаются; содержимое
хранится как байты. Нечитаемый каталог или файл - ошибка
`vfs: не удалось прочитать ...`, код возврата 1.

Пути внутри VFS считаются от корня `/`; поддерживаются `.` и `..`
(выше корня подняться нельзя).

### Команды

| Команда            | Что делает                                          |
|--------------------|-----------------------------------------------------|
| `ls [args]`        | Заглушка: печатает своё имя и аргументы             |
| `cd [args]`        | Заглушка: печатает своё имя и аргументы             |
| `exit [код]`       | Завершает работу; код по умолчанию 0                |
| `vfs-info`         | Источник, число каталогов и файлов, размер, глубина |
| `vfs-tree [путь]`  | Дерево VFS от указанного пути (по умолчанию `/`)    |

Служебные команды `vfs-info` и `vfs-tree` только читают VFS. Без
`--vfs` они сообщают `VFS не подключена`. Реальные `ls` и `cd` для VFS
появятся на этапе 4.

Парсер: слова делятся пробелами; `"..."` - одно слово (внутри `\"` и
`\\`); `'...'` - буквально; `""` - пустой аргумент; `\ ` -
экранированный пробел. Ctrl+D завершает работу, Ctrl+C отменяет ввод.

Коды возврата: 0 - успех, 1 - ошибка команды или VFS, 2 - ошибка
синтаксиса или аргументов, 127 - команда не найдена.

### Стартовый скрипт

Текстовый файл (UTF-8), по одной команде в строке. Пустые строки и
строки, начинающиеся с `#`, пропускаются. Каждая команда выводится с
приглашением, затем идёт её вывод - как в живом диалоге. Выполнение
останавливается на первой ошибке (ненулевой код), эмулятор завершается
с кодом этой ошибки. `exit [код]` в скрипте тоже завершает эмулятор.
Если скрипт выполнен без ошибок, эмулятор переходит в диалог.

### Структура

- `src/shell_emulator/`
  - `parser.py` - разбор строки; `prompt.py` - приглашение;
  - `results.py` - `Result`, коды возврата, `ShellExitError`;
  - `vfs.py` - VFS в памяти (загрузка, пути, дерево, сводка);
  - `context.py` - состояние сеанса (подключённая VFS);
  - `commands.py`, `vfs_commands.py` - команды и их реестр;
  - `repl.py` - диалог; `script.py` - стартовый скрипт;
  - `config.py` - параметры; `app.py` - сборка; `__main__.py` - вход.
- `tests/` - модульные тесты (unittest)
- `examples/vfs/` - тестовые VFS: `minimal`, `several`, `deep`
- `examples/*.emu` - стартовые скрипты эмулятора
- `scripts/` - скрипты реальной ОС, проверяющие параметры и VFS

## Сборка и запуск тестов

Сборка не требуется, нужен только Python 3.9+.

    ./run.sh                                  # интерактивный запуск
    ./run.sh --vfs examples/vfs/deep --script examples/startup_full.emu
    make test                                 # модульные тесты
    make check                                # скрипты реальной ОС
    make all                                  # и то и другое

Скрипты реальной ОС (bash 3.2+, работают на macOS и Linux):
`test_param_vfs.sh`, `test_param_script.sh`, `test_param_all.sh`
(параметры), `test_vfs_minimal.sh`, `test_vfs_files.sh`,
`test_vfs_deep.sh` (варианты VFS: минимальный, несколько файлов,
5 уровней вложенности), `test_vfs_errors.sh` (ошибки), общий запуск -
`scripts/run_all.sh`.

Стартовый скрипт `examples/startup_full.emu` проверяет все команды
этапов 1-3 и все режимы работы с VFS; его последняя строка нарочно
вызывает ошибку, чтобы показать остановку скрипта.

## Примеры использования

    $ ./run.sh --vfs examples/vfs/several
    user@host:~$ vfs-info
    source: /.../examples/vfs/several
    directories: 1
    files: 6
    total size: 157 B
    max depth: 2
    user@host:~$ vfs-tree /docs
    /docs
    ├── guide.txt (26 B)
    └── my notes.txt (36 B)
    user@host:~$ vfs-tree "/docs/my notes.txt"
    /docs/my notes.txt (36 B)
    user@host:~$ vfs-tree /nope
    vfs-tree: /nope: No such file or directory
    user@host:~$ exit
