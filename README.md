# Эмулятор оболочки UNIX (Вариант 19)

## Общее описание

Консольный эмулятор языка оболочки ОС на Python 3.9+ (сторонние
библиотеки не нужны). Реализованы этап 1 (REPL) и этап 2
(конфигурация: параметры командной строки и стартовый скрипт).

## Описание функций и настроек

### Параметры командной строки

| Параметр        | Назначение                                        |
|-----------------|---------------------------------------------------|
| `--vfs DIR`     | Путь к физическому расположению VFS (каталог)     |
| `--script FILE` | Путь к стартовому скрипту с командами эмулятора   |
| `--help`        | Справка                                           |

Оба параметра необязательны. Пути проверяются на существование и
превращаются в абсолютные. Ошибка параметров (нет каталога/файла,
неизвестный параметр, нет значения) - код возврата 2.

При каждом запуске печатается отладочный вывод всех параметров:

    [debug] параметры запуска:
    [debug]   --vfs    = /abs/path/to/vfs
    [debug]   --script = <не задан>

### Стартовый скрипт

Текстовый файл (UTF-8), по одной команде эмулятора в строке.
Пустые строки и строки, начинающиеся с `#`, пропускаются.
Каждая команда показывается с приглашением, затем её вывод - как в
живом диалоге. Выполнение останавливается на первой ошибке
(ненулевой код команды: неизвестная команда, синтаксическая ошибка,
ошибка аргументов); эмулятор завершается с кодом этой ошибки.
Команда `exit [код]` в скрипте тоже завершает эмулятор. Если скрипт
выполнен без ошибок, эмулятор переходит в интерактивный режим.

### Команды и приглашение

Приглашение берётся из ОС: `username@hostname:~$`.

| Команда        | Что делает                                       |
|----------------|--------------------------------------------------|
| `ls [args]`    | Заглушка: печатает своё имя и аргументы          |
| `cd [args]`    | Заглушка: печатает своё имя и аргументы          |
| `exit [код]`   | Завершает работу; код по умолчанию 0             |

Парсер: слова делятся пробелами; `"..."` - одно слово (внутри `\"` и
`\\`); `'...'` - буквально; `""` - пустой аргумент; `\ ` -
экранированный пробел. Ctrl+D завершает работу, Ctrl+C отменяет ввод.
Ошибки: `command not found` (127), `syntax error` (2).

### Структура

- `src/shell_emulator/` - parser.py, prompt.py, commands.py, repl.py,
  config.py (параметры), script.py (стартовый скрипт), app.py (сборка)
- `tests/` - модульные тесты
- `examples/` - стартовые скрипты `*.emu` и пример каталога VFS
- `scripts/` - скрипты реальной ОС для проверки всех параметров

## Сборка и запуск тестов

Сборка не требуется.

    ./run.sh                                  # интерактивный запуск
    ./run.sh --vfs examples/vfs_sample --script examples/startup_ok.emu
    make test                                 # модульные тесты
    make check                                # скрипты реальной ОС

Скрипты реальной ОС (bash, работают и на macOS):
`scripts/test_vfs_param.sh`, `scripts/test_script_param.sh`,
`scripts/test_all_params.sh`, общий запуск - `scripts/run_all.sh`.

## Примеры использования

    $ ./run.sh --script examples/startup_error.emu
    [debug] параметры запуска:
    [debug]   --vfs    = <не задан>
    [debug]   --script = /.../examples/startup_error.emu
    user@host:~$ ls before
    command: ls
    arguments (1): ['before']
    user@host:~$ unknown_command arg
    unknown_command: command not found
    script: остановлен на строке 3 (код 127)
    $ echo $?
    127
